Yahtzee Game (source code on github)
    A Yahtzee game I have made for the ICS3U Course Coding Language: Java with The NetBeans IDE GUI Builder

    Main features of the game:
  • Allows a two-player game
  • The player can choose to start a new game, continue from a previously saved game, or click the game guide from the main menu
  • The game will keep track of the number of rolls left on each turn, the players' name and total score, and the number of rounds played
  • Each player can take turns rolling the dice and tap on a die to lock it
  • The player can click on the combo box of the scoreboard to choose their score and click play to submit
  • The submitted scores will be locked, and players can only click on their own colored combo boxes
  • Automatically keeps track of bonuses and adds them to the total score accordingly
  • Players can click on the SAVE AND EXIT button at the top to save their current game and go back to the main menu. The player can click on resume game on the main menu to load the previously saved game
  • Players can click on the CHECK GAME GUIDE button at the top to save their current game and check the user guide, including the rules. After checking the game guide, the player can either go back to the game or go to the main menu. For both options, the game will be saved
